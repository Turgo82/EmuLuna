# Settings illustrations

Original EmuLuna SVG artwork, covered by the project MIT license. These are
color illustrations inspired by classic desktop preferences, drawn for this
project rather than copied from OpenEmu.

General: blue settings plate and silver gear. Library: blue book with a red
bookmark. Gameplay: amber CRT. Controls: silver directional pad with a violet
edge and cyan button. Cores: green board and processor. System Files: blue
firmware board with a coral BIOS label. Advanced: violet glass flask and cyan
liquid.

The icon engine preserves these colors in selected tabs and renders the SVG
at the display's requested pixel density. The sidebar and gameplay toolbar
continue to use the separate theme-colored outline SVGs.
