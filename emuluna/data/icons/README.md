# Console icons

The active PNG console icons are from OpenEmu and its contributors:
https://github.com/OpenEmu/OpenEmu/tree/master/OpenEmu/SystemPlugins

Restored unchanged from the archived local OpenEmu source / previous Linux
frontend at the user's request. `openemu-icons.json` records SHA-256 hashes and
matching upstream source paths where available. These images retain their
original ownership; the EmuLuna source-code MIT license does not relicense them.
Asset reuse rights have not been independently verified.

The original EmuLuna SVG badges remain available alongside them as alternatives.
The EmuLuna application icon is separate, in `../branding/`.
