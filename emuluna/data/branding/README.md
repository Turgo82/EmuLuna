## Compact app icon

Created for EmuLuna with the built-in image-generation tool on 2026-09-19.
Original PNG pixels and alpha are preserved.

Prompt: Create a finished desktop application icon for a new standalone retro-game library and emulator frontend named EmuLuna. Use case: logo-brand. Asset: one square app icon, no text or lettering. A distinctive softly luminous crescent moon embraces a simple game-controller silhouette, with a readable cross-shaped D-pad and two small round buttons. Midnight indigo and lavender with a restrained moonlight cyan accent, matching a dark desktop app. Polished dimensional enamel or softly sculpted material, clean silhouette and very few details, legible at 32 pixels. Centered single icon with generous transparent padding, genuinely transparent background outside the icon, no mockup, no frame of a screen, no watermark, no existing console brand or OpenEmu imagery. Output a single 1024x1024 PNG suitable as the main EmuLuna app icon.
