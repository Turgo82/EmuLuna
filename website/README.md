# EmuLuna website

This directory contains the source for the EmuLuna product website published at:

https://emuluna-retro-library.turgo82.chatgpt.site

The site is plain static HTML, CSS, and JavaScript. Its publishable files live in
`dist/`, and `.openai/hosting.json` identifies the existing Sites project. Serve
`dist/` with any static web server for local development.

The full EmuLuna logo, Luna mascot, and application screenshots were supplied for
the project. Controller artwork visible in the Controls screenshot is credited
to Pinapple_Graphics. Game artwork and trademarks belong to their respective
owners. No ROMs, BIOS files, user database, or save files are included.
